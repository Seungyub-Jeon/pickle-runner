# 실행기 v0.3.3

`terminal.run`은 같은 macOS 사용자 권한의 원본 셸을 실행한다. 인증정보 두 계층을 가진 호출자는 이 사용자의 파일·설치 CLI에 접근할 수 있으며 샌드박스로 격리되지 않는다.

[긴급 중지](../docs/OPERATIONS.md#긴급-중지) · [소개](../README.md) · [설치](../docs/SETUP.md) · [운영](../docs/OPERATIONS.md) · [에이전트 지침](PICKLE.md)

API 명세는 openapi.json이며 호스트는 예시다. 실제 접속 주소와 자격증명은 비공개 클라이언트 설정으로 전달한다.
